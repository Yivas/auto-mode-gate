# Contributing

## Bug reports

Use the bug report form for reproducible defects in a supported version. Search existing issues
first and include the affected version, host, operating system, reproduction steps, expected
behavior, and observed behavior.

Remove credentials, prompts, commands, logs, paths, identifiers, and other private data before
submitting evidence.

## Security reports

Do not report undisclosed vulnerabilities in a public issue. Follow the
[security policy](.github/SECURITY.md) and use GitHub private vulnerability reporting.

## Pull requests

Pull requests are not currently accepted. Open an issue before proposing a change so the maintainer
can confirm whether it fits the project's scope.

All project interactions must follow the [Code of Conduct](CODE_OF_CONDUCT.md).
