Auto Mode Gate is an independent MIT-licensed project maintained for OpenCode and Pi. The public repository accepts reproducible bug reports and private security reports; pull requests are not currently reviewed or merged.

## Support and security

- Report reproducible defects through the [GitHub issue form](https://github.com/Yivas/auto-mode-gate/issues/new/choose).
- Report undisclosed vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Yivas/auto-mode-gate/security/advisories/new).
- Read the [contribution policy](https://github.com/Yivas/auto-mode-gate/blob/main/CONTRIBUTING.md).
- Follow the [Code of Conduct](https://github.com/Yivas/auto-mode-gate/blob/main/CODE_OF_CONDUCT.md).

Remove credentials, tokens, prompts, identifiers, active configuration values, and other private data from public reports. Redact private values inside commands, logs, and paths while keeping enough detail to reproduce a defect.

## License and independence

The project is distributed under the [MIT License](https://github.com/Yivas/auto-mode-gate/blob/main/LICENSE). It is independent and is not affiliated with Anthropic, OpenCode, Pi, or OpenCode Swarm.

## Upstream design study

The design study references OpenCode Swarm at commit [`50033bc1e0a0d943433701042fed90b2a791f7fe`](https://github.com/ZaxbyHub/opencode-swarm/commit/50033bc1e0a0d943433701042fed90b2a791f7fe), which is MIT licensed. Auto Mode Gate is an independent implementation and excludes Swarm's orchestration system.

The project does not include architect, coder, reviewer, planning, phases, `.swarm` state, memory, QA, worktrees, council, cadence, evidence storage, task state, or other multi-agent orchestration features.

Read the [upstream provenance record](https://github.com/Yivas/auto-mode-gate/blob/main/docs/upstream.md) for source locations, revision, license, attribution, and extraction rules.
