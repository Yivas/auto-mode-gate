---
title: Configure the gate
description: Configure global policy, trusted executable paths, and optional project tightening.
---

Auto Mode Gate reads one global JSON file and, when present, `.auto-mode-gate.json` from the project root. Each host adapter reads configuration when it starts, so restart or reload the host after changing a file.

## Global configuration

On Windows, the default global path is:

```text
%APPDATA%\auto-mode-gate\config.json
```

The full resolution order is:

1. `$XDG_CONFIG_HOME/auto-mode-gate/config.json` when `XDG_CONFIG_HOME` is set.
2. `%APPDATA%\auto-mode-gate\config.json` on Windows.
3. `~/.config/auto-mode-gate/config.json` elsewhere.

Configured roots and every file path must be absolute for the current operating system. Relative roots fail closed.

Package `0.2.0` supports the deterministic keys and the optional `permissionJudge` block below. Package `0.1.0` does not support that block; adding it makes the strict configuration fail closed.

A global configuration for version `0.2.0` looks like this:

```json
{
  "mode": "enforce",
  "shell": "powershell",
  "trustedExecutablePaths": [
    "C:\\Windows\\System32\\where.exe",
    "C:\\Program Files\\Git\\cmd\\git.exe"
  ],
  "permissionJudge": {
    "enabled": true,
    "model": {
      "provider": "example-provider",
      "id": "example-model"
    },
    "timeoutMs": 15000
  }
}
```

| Key | Values | Meaning |
|-|-|-|
| `mode` | `off`, `shadow`, `enforce` | Controls whether denied actions block. Defaults to `enforce`. |
| `shell` | `bash`, `powershell`, `cmd` | Required before a Bash call can be allowed. |
| `trustedExecutablePaths` | Absolute path array | Exact authority for narrow read-only allowances. |
| `logPath` | Absolute file path | Optional sanitized JSONL decision log. |
| `permissionJudge` | Strict object | Global opt-in, default Pi model, and timeout from 1,000 through 120,000 ms. |

Create the log directory before starting the host when `logPath` is configured.

## Project configuration

Project configuration can also disable the judge or reduce its timeout:

```json
{
  "mode": "enforce",
  "trustedExecutablePaths": [
    "C:\\Windows\\System32\\where.exe"
  ],
  "permissionJudge": {
    "enabled": false
  }
}
```

A project can tighten `shadow` to `enforce`, remove trusted paths, disable the judge, or reduce its timeout. It cannot enable a globally `off` gate, relax `enforce`, set the shell, add trust absent from the global file, set a log path, authorize the judge, change its model, or increase its timeout.

Each configuration file may contain at most 64 KiB, and each trusted-path list may contain at most 256 entries. Unknown keys, invalid JSON, relative paths, oversized input, and unreadable files fail closed.

## Modes

- `enforce`: denied actions block.
- `shadow`: policy and logs run, but actions do not block.
- `off`: the adapter remains loaded but does not block.

`shadow` is an observation mode, not a security control.

## Configuration failures

Missing shell evidence, malformed input, malformed configuration, unsupported syntax, and internal errors fail closed. Missing or malformed judge authorization disables the judge. A configured model that Pi does not expose blocks without fallback. The gate does not resolve `PATH` or rewrite commands to manufacture executable identity.
