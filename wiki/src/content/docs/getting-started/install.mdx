Review the package source before installing. OpenCode plugins and Pi extensions run with your
system permissions.

:::note[Published release and host baselines]
Version `0.4.4` targets the validated OpenCode `1.18.18` and Pi `0.84.2` baselines. Package
`0.1.0` remains deterministic-only and blocks all ambiguity.
:::

:::caution[OpenCode 2.x is not supported yet]
OpenCode 2.x is not supported yet: it does not load this plugin, so the gate gives no protection
there. Use OpenCode `1.18.18` until a release adds 2.x support.
:::

## Install from npm

Choose the host that loads the gate. OpenCode and Pi keep separate installations and policy paths.

<Tabs syncKey="installation-host">
  <TabItem label="OpenCode" icon="puzzle">
    1. Install the package for the current project (add `--global` for every project):

       ```text
       opencode plugin auto-mode-gate@0.4.4
       ```

       Or add the entry to the `plugin` array of your project or global `opencode.json` without
       removing existing plugins:

       ```json
       {
         "$schema": "https://opencode.ai/config.json",
         "plugin": ["auto-mode-gate@0.4.4"]
       }
       ```

    2. Restart OpenCode so it resolves the configured npm plugin.
    3. Confirm discovery and pre-tool behavior under [Verify and operate](../../guide/verify-and-operate/).
  </TabItem>
  <TabItem label="Pi" icon="puzzle">
    Version `0.4.4` requires Pi `0.84.2` for persistent judge controls and explicit
    secondary-model thinking.

    1. Install globally (add `-l` for a project-local installation):

       ```text
       pi install npm:auto-mode-gate@0.4.4
       ```

    2. Confirm the package entry and runtime state under [Verify and operate](../../guide/verify-and-operate/).
  </TabItem>
</Tabs>

For a local checkout or a source loader, follow [install from a checkout](../install-from-checkout/).

## Remove an installation

<Tabs syncKey="installation-host">
  <TabItem label="OpenCode" icon="puzzle">
    OpenCode `1.18.18` has no plugin removal subcommand.

    1. Run `opencode debug config` to locate the configuration file that supplied the plugin.
    2. Remove only the Auto Mode Gate entry from its `plugin` array.
    3. Restart OpenCode and confirm the plugin no longer appears.
  </TabItem>
  <TabItem label="Pi" icon="puzzle">
    Remove the package with the same scope used to install it:

    ```text
    pi remove npm:auto-mode-gate
    pi remove npm:auto-mode-gate -l
    ```
  </TabItem>
</Tabs>
