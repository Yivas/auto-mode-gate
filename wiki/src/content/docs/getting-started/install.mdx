Install the package only after reviewing its source. OpenCode plugins and Pi extensions run with the
user's system permissions.

:::note[Choose the required behavior]
Package `0.4.1` refreshes public presentation and includes the same runtime behavior as 0.4.0:
persistent Pi controls, host-owned policy paths, and safe migration from shared `0.2.0`
configuration. Package `0.1.0` remains deterministic-only and blocks all ambiguity.
:::

## Install from npm

Choose the host that should load the gate. Each host keeps its own installation and policy paths.

<Tabs syncKey="installation-host">
  <TabItem label="OpenCode" icon="puzzle">
    Declare the package in the `plugin` array of your project or global `opencode.json`:

    ```json
    {
      "$schema": "https://opencode.ai/config.json",
      "plugin": ["auto-mode-gate@0.4.1"]
    }
    ```

    Merge that entry into the existing array without removing other plugins or configuration.
    OpenCode resolves configured npm plugins when it starts.

    You can also install it for the current project:

    ```text
    opencode plugin auto-mode-gate@0.4.1
    ```

    Add `--global` to install it for every project. Verify the resolved plugin list:

    ```text
    opencode debug config
    ```

    The resolved `plugin` list must contain the Auto Mode Gate entry.
  </TabItem>
  <TabItem label="Pi" icon="puzzle">
    Version 0.4.1 requires Pi 0.84.2 for persistent judge controls and explicit secondary-model
    thinking, as first documented for 0.4.0.

    Install globally:

    ```text
    pi install npm:auto-mode-gate@0.4.1
    ```

    Add `-l` for a project-local installation. Verify the package entry:

    ```text
    pi list
    ```
  </TabItem>
</Tabs>

## Install from a checkout

The source loader flow uses one small loader file and does not edit host settings. Run the commands
from the checkout root, keep the checkout at the same path, and restart the host after installing
the loader. Set `$scope` to `project` or `global`; `$targetProject` is used only for project scope.

<Tabs syncKey="installation-host">
  <TabItem label="OpenCode" icon="puzzle">
    ```powershell
    $scope = "project"
    $targetProject = "C:\path\to\project"
    $source = [System.Uri]::new((Resolve-Path .\src\opencode-runtime.ts).Path).AbsoluteUri
    $pluginRoot = if ($scope -eq "project") {
      Join-Path (Resolve-Path $targetProject).Path ".opencode\plugins"
    } elseif ($env:OPENCODE_CONFIG_DIR) {
      Join-Path $env:OPENCODE_CONFIG_DIR "plugins"
    } else {
      Join-Path $HOME ".config\opencode\plugins"
    }
    New-Item -ItemType Directory -Force $pluginRoot | Out-Null
    "export { AutoModeGatePlugin } from `"$source`";" |
      Set-Content -Encoding utf8 (Join-Path $pluginRoot "auto-mode-gate.ts")
    ```

    Verify discovery:

    ```powershell
    if ($scope -eq "project") {
      Push-Location $targetProject
      try { opencode debug config } finally { Pop-Location }
    } else {
      opencode debug config
    }
    ```
  </TabItem>
  <TabItem label="Pi" icon="puzzle">
    ```powershell
    $scope = "project"
    $targetProject = "C:\path\to\project"
    $source = [System.Uri]::new((Resolve-Path .\src\pi-runtime.ts).Path).AbsoluteUri
    $extensionRoot = if ($scope -eq "project") {
      Join-Path (Resolve-Path $targetProject).Path ".pi\extensions\auto-mode-gate"
    } elseif ($env:PI_CODING_AGENT_DIR) {
      Join-Path $env:PI_CODING_AGENT_DIR "extensions\auto-mode-gate"
    } else {
      Join-Path $HOME ".pi\agent\extensions\auto-mode-gate"
    }
    New-Item -ItemType Directory -Force $extensionRoot | Out-Null
    "export { default } from `"$source`";" |
      Set-Content -Encoding utf8 (Join-Path $extensionRoot "index.ts")
    ```

    Pi loads project extensions after the project is trusted. Check startup without contacting
    model providers:

    ```powershell
    if ($scope -eq "project") {
      Push-Location $targetProject
      try { pi --offline --list-models } finally { Pop-Location }
    } else {
      pi --offline --list-models
    }
    ```
  </TabItem>
</Tabs>

## Remove an installation

<Tabs syncKey="installation-host">
  <TabItem label="OpenCode" icon="puzzle">
    OpenCode 1.18.18 has no plugin removal subcommand. Use `opencode debug config` to locate the
    configuration that supplied the plugin, remove only the matching Auto Mode Gate entry from its
    `plugin` array, restart OpenCode, and confirm that the plugin no longer appears.
  </TabItem>
  <TabItem label="Pi" icon="puzzle">
    Remove the package with the same scope used to install it:

    ```text
    pi remove npm:auto-mode-gate
    pi remove npm:auto-mode-gate -l
    ```
  </TabItem>
</Tabs>

For a source installation, delete only the loader created for Auto Mode Gate:

```powershell
Remove-Item <plugin-root>\auto-mode-gate.ts
Remove-Item -Recurse <extension-root>\auto-mode-gate
```
